Who dies under a drug? Mass-aware optimal transport for single-cell perturbation atlases.

Treated and control cells are unpaired point clouds, and drugs kill cells. We transport control cells onto treated cells with the transported mass fixed to the measured viability. The proposed AA-TI-Sinkhorn solver needs a number of sweeps that stays flat in the marginal penalty τ, while plain Sinkhorn needs tens of thousands.

Solver race

The same VC-UOT instance is handed to the three unbalanced solvers, which run side by side. Push τ/ε up and the plain scaling algorithm stalls, because its dual translation mode contracts by only λ = τ/(τ+ε) per sweep. Translation invariance removes that mode, and Anderson extrapolation accelerates the rest.

Three results in one screen

The optimisation results that support the demo.

Prop. 1: mass

Symmetric KL-UOT with C ≡ 0 transports

mass = ρ^((τ+ε)/(2τ+ε)) → √ρ

VC-UOT (τ_b = ∞) transports exactly ρ, and the survival scores are s_i = e^{-f_i/τ} with mean ρ.

Prop. 2: the slow mode

If Sinkhorn starts at f* + t·1, then after k sweeps

f^k = f* + (λ_a λ_b)^k · t · 1, λ = τ/(τ+ε)

So the iteration count grows like τ/ε, and VC-UOT needs about twice as many sweeps as symmetric UOT. Both effects match the measurements.

AA-TI-Sinkhorn

An exact translation step t* = (log A − log B)/(1/τ_a + 1/τ_b) removes the slow mode. Type-II Anderson extrapolation (memory 5) accelerates the rest, and a residual safeguard keeps every step at least as good as a TI step.

sweeps: O(τ/ε) → O(1) in τ
